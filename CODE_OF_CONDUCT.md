# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be kind and constructive, assume good intent, and keep discussion about the work. Harassment,
insults and personal attacks aren't tolerated. Comments, issues or pull requests that break this may be
edited, locked or removed, and repeat offenders blocked.

Report problems to the maintainer privately through GitHub (the maintainer's profile page or the
Security tab's private report form).
